# Project Summary

This repository contains a compact collection of GAN experiments implemented in Python. It focuses on two primary implementations:

- DCGAN: Deep Convolutional Generative Adversarial Network implemented in `DCGAN/DCGAN_script.py` and demonstrated in `DCGAN/deep_convolutional_GAN.ipynb`.
- Vanilla GAN: Educational implementation and exploration in `GAN/GAN.ipynb` and helper scripts in `GAN/`.

Goals:
- Demonstrate practical implementation of GAN architectures.
- Provide runnable notebooks to reproduce sample outputs.
- Offer clear documentation and reproducibility for recruiters and reviewers.

Key highlights:
- Notebook-based walkthroughs for reproducibility and demonstration.
- Scripts suitable for running experiments locally on GPU or CPU.
- Guidance for generating visuals and storing model artifacts in `results/` and `models/`.
